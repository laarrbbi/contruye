# ПРИЛОЖЕНИЕ A — СПРАВОЧНИК ПАРТНЁРОВ ПО ПРОВИНЦИЯМ И ФАЗАМ

> **Как пользоваться:** найдите свою провинцию. Для каждой фазы указано учреждение или тип партнёра и для чего он вам нужен.
> Названия коллегий и ведомств иногда меняются: проверьте их в официальных поисковиках ниже, прежде чем идти.

## Официальные поисковики (действуют по всей Испании)

| Вам нужно | Поисковик |
|---|---|
| Реестр собственности (Registro de la Propiedad) участка, notas simples | registradores.org |
| Нотариус | notariado.org |
| Кадастр (кроме Navarra и País Vasco) | sede.catastro.gob.es |
| Коллегия архитекторов (Colegio de Arquitectos) | cscae.com (Consejo Superior de Colegios de Arquitectos) |
| Коллегия технических архитекторов (Colegio de Aparejadores y Arquitectos Técnicos) | arquitectura-tecnica.com (CGATE) |
| Коллегия агентов по недвижимости (Colegio de Agentes de la Propiedad Inmobiliaria) | consejocoapis.org |
| Коллегия управляющих недвижимостью (Colegio de Administradores de Fincas) | cgcafe.org |
| Коллегия страховых посредников (Colegio de Mediadores de Seguros) | consejo general de los colegios de mediadores de seguros |
| Аккредитованные оценочные компании | Registro de entidades del Banco de España (bde.es) |
| Аукционы | subastas.boe.es · электронный портал AEAT · электронный портал Социального страхования |
| Государственная земля | CASA47 (ранее SEPES) |
| Ассоциации девелоперов | apce.es (Asociación de Promotores Constructores de España) |
| Бассейновые управления | MITECO, карта гидрографических округов |
| Электросетевая компания по адресу | CNMC или CUPS на любом счёте из этого района |
| Противодействие отмыванию денег | sepblac.es |

# ДОДАТОК A — ДОВІДНИК ПАРТНЕРІВ ЗА ПРОВІНЦІЯМИ ТА ФАЗАМИ

> **Як користуватися:** знайдіть свою провінцію. Для кожної фази вказано установу або тип партнера і для чого він вам потрібен.
> Назви колегій і відомств інколи змінюються: перевірте їх в офіційних пошукових системах нижче, перш ніж іти.

## Офіційні пошукові системи (діють по всій Іспанії)

| Вам потрібно | Пошукова система |
|---|---|
| Реєстр власності (Registro de la Propiedad) ділянки, notas simples | registradores.org |
| Нотаріус | notariado.org |
| Кадастр (крім Navarra і País Vasco) | sede.catastro.gob.es |
| Колегія архітекторів (Colegio de Arquitectos) | cscae.com (Consejo Superior de Colegios de Arquitectos) |
| Колегія технічних архітекторів (Colegio de Aparejadores y Arquitectos Técnicos) | arquitectura-tecnica.com (CGATE) |
| Колегія агентів з нерухомості (Colegio de Agentes de la Propiedad Inmobiliaria) | consejocoapis.org |
| Колегія управителів нерухомості (Colegio de Administradores de Fincas) | cgcafe.org |
| Колегія страхових посередників (Colegio de Mediadores de Seguros) | consejo general de los colegios de mediadores de seguros |
| Акредитовані оціночні компанії | Registro de entidades del Banco de España (bde.es) |
| Аукціони | subastas.boe.es · електронний портал AEAT · електронний портал Соціального страхування |
| Державна земля | CASA47 (раніше SEPES) |
| Асоціації девелоперів | apce.es (Asociación de Promotores Constructores de España) |
| Басейнові управління | MITECO, карта гідрографічних округів |
| Електророзподільна компанія за адресою | CNMC або CUPS на будь-якому рахунку з цього району |
| Запобігання відмиванню коштів | sepblac.es |

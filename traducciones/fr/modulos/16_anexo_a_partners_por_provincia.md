# ANNEXE A — ANNUAIRE DES PARTENAIRES PAR PROVINCE ET PAR PHASE

> **Comment l'utiliser :** cherchez votre province. Pour chaque phase, vous avez l'institution ou le type de partenaire, et ce pour quoi vous en avez besoin.
> Les noms des ordres professionnels et des organismes changent parfois : vérifiez-les dans les moteurs de recherche officiels ci-dessous avant de vous déplacer.

## Moteurs de recherche officiels (valables dans toute l'Espagne)

| Vous cherchez | Moteur de recherche |
|---|---|
| Le registre foncier du terrain (Registro de la Propiedad), notas simples | registradores.org |
| Un notaire | notariado.org |
| Le cadastre (sauf Navarra et País Vasco) | sede.catastro.gob.es |
| L'ordre des architectes (Colegio de Arquitectos) | cscae.com (Consejo Superior de Colegios de Arquitectos) |
| L'ordre des architectes techniques (Colegio de Aparejadores y Arquitectos Técnicos) | arquitectura-tecnica.com (CGATE) |
| L'ordre des agents immobiliers (Colegio de Agentes de la Propiedad Inmobiliaria) | consejocoapis.org |
| L'ordre des syndics (Colegio de Administradores de Fincas) | cgcafe.org |
| L'ordre des intermédiaires d'assurance (Colegio de Mediadores de Seguros) | consejo general de los colegios de mediadores de seguros |
| Les sociétés d'expertise agréées | Registro de entidades del Banco de España (bde.es) |
| Les ventes aux enchères | subastas.boe.es · site électronique de l'AEAT · site électronique de la Sécurité sociale |
| Le foncier public de l'État | CASA47 (anciennement SEPES) |
| Les associations de promoteurs | apce.es (Asociación de Promotores Constructores de España) |
| Les organismes de bassin | MITECO, carte des districts hydrographiques |
| Le distributeur d'électricité d'une adresse | CNMC, ou le CUPS de n'importe quelle facture du secteur |
| La prévention du blanchiment | sepblac.es |

# ما قبل التسليم

> **الهدف:** أن يتسلّم كل مشترٍ مسكناً بلا عيوب، وأن يكون كل شيء جاهزاً لدى الموثّق قبل يوم التوقيع.
> **المدة:** 70 دقيقة · **النتيجة:** قوائم الإصلاحات مغلقة، ووثائق التسليم لكل مسكن، وجدول التوقيعات.

## القوانين المطبّقة

| النص القانوني | ما يهمّك |
|---|---|
| LOE، المادة 17 | ما لا يُصلح الآن يُطالب به لاحقاً بموجب الضمان |
| TRLGDCU، المادة 89.3 | المصاريف التي لا يمكنك تحميلها للمشتري |
| اللائحة التوثيقية (Reglamento Notarial)، المادة 126 | المشتري المستهلك هو من يختار الموثّق |
| Ley 5/2019، المادتان 14 و15 | رهن المشتري: يسلّمه البنك الوثائق (FEIN، FiAE) قبل 10 أيام تقويمية على الأقل، ويحضر المشتري أمام الموثّق لمحضر مسبق قبل يوم التوقيع على الأقل |
| Ley 10/2010 | التحقق من الهوية ومصدر الأموال قبل التوقيع |

## إلى أين تتوجّه

| من | ماذا تطلب |
|---|---|
| **المقاول** | إصلاح الملاحظات في الموعد (على حساب الاستقطاع إذا لم يلتزم) |
| **الموثّق** | جدول التوقيعات، ومسودة العقد، ومخصّص المصاريف |
| **بنك المطوّر** | شهادة الدين لكل مسكن وإيصال السداد أو وثائق الحلول |
| **بنوك المشترين** | تاريخ توقيع كل رهن |
| **البلدية** | القيم المساحية وبيانات ضريبة القيمة الزائدة لكل مسكن |

## الدرس 10.1 — الإصلاحات (snagging)

- **الجولة 1 · داخلية (قبل 6-8 أسابيع):** يراجع فني المطوّر + رئيس الورشة كل مسكن بورقة ملاحظات لكل غرفة. ويصلح المقاول.
- **الجولة 2 · مع المشتري (قبل 3-4 أسابيع):** زيارة مرافَقة، يدوّن فيها المشتري العيوب، وتُوقَّع ورقة ما قبل التسليم مع مهلة للإصلاح.
- **الجولة 3 · للتحقق:** فحص نهائي قبل التوقيع.
- **ما يجب مراجعته:**

| المنطقة | النقاط |
|---|---|
| التشطيبات | الضربات على الجدران والأسقف، والدهان، وفواصل الأرضيات، والخدوش في الأرضيات والزجاج |
| النجارة الداخلية | إغلاق الأبواب، والمقابض والمفصلات، والخزائن |
| النجارة الخارجية | إغلاق النوافذ وعزلها، والستائر، والإحكام |
| الكهرباء | كل نقاط الإنارة والمقابس، وقواطع التسرّب، والإنتركم المرئي |
| السباكة | الضغط، والماء الساخن، والتصريف، والسيفونات، وعدم وجود تسرّبات |
| التكييف | عمل الطاقة الهوائية الحرارية، أو المكيّفات المنفصلة، أو التدفئة الأرضية |
| الرطوبة | الأسقف تحت الشرفات والسطح، والطوابق السفلية |
| الاتصالات | المقابس والألياف في كل غرفة |
| المرافق المشتركة | المصعد، والإنارة، وأبواب المرآب، والحدائق |

- **نصيحة:** استخدم تطبيقاً أو ورقة بالصور وأغلق كل نقطة بتاريخ وتوقيع.

## الدرس 10.2 — الوثائق لكل مسكن

| الوثيقة | ملاحظة |
|---|---|
| نسخة العقد الموثّق (بعد التوقيع) | يسلّمها الموثّق |
| شهادة وثيقة العشر سنوات | رقم الوثيقة وشركة التأمين |
| ضمانات الأجهزة | الطاقة الهوائية الحرارية، والأجهزة المنزلية إن وُجدت |
| دليل الاستخدام والصيانة | مستخرج من سجل المبنى |
| مخططات المسكن | مع المساحات ومواقع اللوحات الكهربائية وصمامات القطع |
| شهادة وملصق كفاءة الطاقة | للمبنى المنتهي |
| شهادة الصلاحية للسكن (cédula de habitabilidad) | في CCAA التي تشترطها |
| بيانات اتحاد الملاك | النظام الداخلي، والاشتراك، والمدير |
| بيانات الخدمات | رمز CUPS الكهربائي، وعداد المياه، و CIE |
| مجموعات المفاتيح وأجهزة التحكم | المسكن، والمدخل، والمخزن، والمرآب |

- **لكل مشترٍ، قبل استدعائه:** تأكّد من أنه أوفى بدفعات العقد، وراجع وضع الدفعات والضرائب والمصاريف المترتبة على كل طرف.
- **أكمل ملف التسليم** بـ: البيانات التسجيلية للمسكن وملحقاته؛ وبطاقات ورموز الدخول؛ وقواعد اتحاد الملاك، وبيانات المدير، والاشتراكات المتوقعة؛ ومحضر المعاينة بالملاحظات والتزامات الإصلاح.
- **أثناء الزيارة** اشرح طريقة عمل الأجهزة والتكييف والتهوية والمنزل الذكي إن وُجد.

## الدرس 10.3 — الموثّق

- **قبل 3-4 أسابيع:**
  - يختار المشتري الموثّق (حق المستهلك). اعرض موثّقك دون فرضه.
  - أرسل إلى كل موثّق: البناء الجديد والتقسيم الأفقي المسجّلين، ورخصة أو تصريح السكن الأول، والشهادة إن انطبقت، وتأمين العشر سنوات، وشهادة الطاقة، ونوتا سيمبلي (nota simple) محدّثة للعقار، وشهادة اتحاد الملاك بعدم وجود ديون.
  - اطلب من البنك **شهادة الدين** لكل عقار وإيصال السداد لشطب حصته (أو وثائق الحلول إذا اختاره المشتري).
  - أعدّ **كشف التصفية** لكل مشترٍ: السعر، والدفعات المستلمة مع IVA، والمبلغ المتبقي.
- **يحضر المشتري:** DNI أو NIE، ووثائق مصدر الأموال، وإثباتات الدفعات السابقة، والرهن الذي يُوقَّع في اليوم نفسه (بعد تسلّم الوثائق قبل 10 أيام تقويمية على الأقل وإجراء المحضر المسبق لدى الموثّق قبل يوم على الأقل، Ley 5/2019).
- **وسائل الدفع:** يتحقق الموثّق من كل دفعة (شيك اسمي أو تحويل). لا نقد فوق الحد القانوني.
